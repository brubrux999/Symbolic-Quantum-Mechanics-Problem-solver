# :cat2: Symbolic Quantum Mechanics Problem solver

This repository is part of the **Project** for the subject "Selected Topics in Computational Physics I: Symbolic Computing" (2027-1).

Using the Python **SymPy** library, the aim is to solve simple one-dimensional quantum mechanics problems, such as infinite potential wells, potential barriers, and the quantum harmonic oscillator.
Additionally, the project involves performing other calculations—such as Fourier transforms, probability densities, expectation values, and variances—using this library.

## :pushpin: Objectives

- [] Necessary classes and objects
- [] Necessary symbols and expressions
- [] Potential well
- [] Potential barrier
- [] Quantum harmonic oscillator
- [] Fourier transform
- [] Probability density
- [] Expectation value
- [] Variance

## :soon: Future Updates

Through continuous learning with SymPy, the aim is to apply the knowledge gained to add to or modify the project's features and structure.

# :cat2: Solucionador de problemas de Mecánica Cuántica

Este repositorio forma parte del **Proyecto** para el curso de "Temeas Selecto de Física Computacional I: Cómputo Simbólico" (2027-1).

Mediante el uso de la librería **SymPy** de Python, se busca resolver problemas simples de la Mecánica Cuántica en una dimensión, como lo son pozos de potencial infinito, barreras de potencial y oscilador armónico cuántico.
Asimismo, se buscan otros cálculos como Transformadas de Fourier, Densidades de probabilidad, Valores esperados, Varianzas, entre otros valores mediante el uso de esta librería.

## :pushpin: Objetivos

- [] Clases y objetos necesarios
- [] Simbolos y expresiones necesarias
- [] Pozo de potencial
- [] Barrera de potencial
- [] Oscilador armónico cuántico
- [] Transformada de Fourier
- [] Densidad de probabilidad
- [] Valor esperado
- [] Varianza
